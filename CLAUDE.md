# Dragon SEO

SEO-скил для AI-агентов: написание постов, контент-стратегия, GEO/AI-оптимизация, E-E-A-T, технический SEO.

**Источники:**
- coreyhaines31/marketingskills (copywriting, content-strategy, ai-seo, copy-editing)
- AgriciDaniel/claude-seo (E-E-A-T, технический SEO, GEO)
- zubair-trabzada/geo-seo-claude (GEO scoring)
- TheCraigHewitt/seomachine (контент-продакшн)
- inhouseseo/superseo-skills (анти-AI-слоп)

**Команды:**
- `dragon post <тема>` — написать SEO-пост
- `dragon strategy` — контент-стратегия
- `dragon audit <url>` — SEO-аудит
- `dragon geo <url>` — AI-видимость
- `dragon brief <тема>` — SEO-бриф
- `dragon news <тема>` — новость
- `dragon improve <текст>` — редактура

**Установка:** скопировать SKILL.md и references/ в папку навыков вашего AI-агента.
